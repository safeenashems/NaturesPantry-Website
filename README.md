# Nature's Pantry – Supermarket Website

A dynamic supermarket website built with vanilla JavaScript, featuring user sign up and login, and product management.

🔗 **Live demo:** https://safeenashems.github.io/NaturesPantry-Website/

## Features
- Sign up and login forms
- After login, full CRUD on products: add, view, edit and delete
- Home page with About, Categories (loaded through an API call) and Contact Us sections

## Built With
HTML, CSS, JavaScript (no frameworks), REST API

## Note
Login and data run in the browser only (no backend or database), so this project is for learning and demonstration.

## Run Locally
1. Clone: `git clone https://github.com/safeenashems/NaturesPantry-Website.git`
2. Open `index.html` in your browser
